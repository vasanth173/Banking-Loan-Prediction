# 🏦 Banking Loan Prediction System

A Machine Learning-based web application to predict loan eligibility and recommended loan amounts.

## Features
- Individual Customer Loan Prediction
- Bulk Customer Prediction using CSV
- Loan Approval / Rejection Prediction
- Recommended Loan Amount
- Dashboard Analytics
- Approval Rate Visualization
- Downloadable Prediction Report

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Machine Learning Algorithms
- Decision Tree Classifier
- Decision Tree Regressor

## Dataset
This project uses 2,000 synthetic customer records for educational purposes.

## How to Run

1. Clone the repository:
   `git clone https://github.com/vasanth173/Banking-Loan-Prediction.git`

2. Install dependencies:
   `pip install streamlit pandas scikit-learn joblib`

3. Run the application:
   `python -m streamlit run app.py`
